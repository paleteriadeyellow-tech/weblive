⚙️ Configurar — Jarrón (bote regalos)

Personaliza el color del jarrón y define el tamaño de los regalos según su precio en monedas/diamantes. Puedes añadir tantos umbrales como quieras.

Cada umbral cubre un rango: desde ese valor hasta el siguiente umbral más alto. Ej.: si pones 100 y luego 200, los regalos de 100 a 199 monedas usan el tamaño del primer umbral; al llegar a 200, ya usa el del siguiente. El umbral más alto cubre todo lo que esté por encima.

🏀 Configurar — Pelotas de fans

Cae una pelota con la foto de perfil del donador cuando alcanza el umbral. El conteo se acumula por usuario guardando el sobrante (ej.: con umbral 100, un regalo de 500 = 5 pelotas; 150 = 1 pelota y quedan 50 pendientes).

🌟 Pelota dorada: cuando alguien se vuelve super fan cae una pelota especial con su foto, más grande y con borde/brillo dorado, por encima de las demás. Se activa sola con el evento de super fan de TikTok (también suma el bono super fan en la pestaña «Usuario y Puntos»).

🎡 Configurar — Ruleta / sorteo

Elige cómo entran los participantes. Pulsa Recolectar en la tarjeta para empezar a registrar entradas. Cada usuario cuenta una sola vez.

Quien escriba esta palabra en el chat entra al sorteo (ej. «yo», «sorteo», «!participo»).

🪝 Webhook y Configuración

Ejecuta tus acciones desde herramientas externas (OBS, Stream Deck, scripts) y conecta el panel con RCON, OBS y Streamer.bot. Funciona solo en la app de escritorio.

⭐
Esta función es Solo Premium
El Webhook y la conexión con OBS / RCON / Streamer.bot están disponibles en el plan Premium. Mejora tu plan para activarlos.
  • Puedes usar esto en OBS Browser Source, Stream Deck (Petición Web), o scripts de Python/NodeJS.
  • Si tienes el mismo nombre en dos acciones, se ejecutará la primera que encuentre.
  • Para agregar varios datos en una URL, usa & después del primer parámetro. Ejemplo: ?name=ACTION_TEST&username=interactive
  • Si un valor tiene espacios o caracteres especiales, debe ir codificado. Ejemplo: Hola mundo → Hola%20mundo

1. Obtener lista de acciones

Devuelve un JSON con el id y nombre de todas las acciones disponibles en el perfil actual.

GETListar Acciones http://localhost:3199/get_actions

2. Ejecutar acción por ID

La forma más segura de ejecutar una acción. El ID no cambia aunque cambies el nombre.

GET/POSTEjemplo ID 1 http://localhost:3199/execute_action?id=1

3. Ejecutar acción por Nombre

Útil si prefieres usar el nombre exacto de la acción. No distingue mayúsculas/minúsculas.

GET/POSTEjemplo por Nombre http://localhost:3199/execute_action?name=ACTION_TEST

Enviar datos personalizados a la acción

Puedes agregar datos extra en la URL para que la acción los use como variables. Estos datos pueden reemplazar valores como {username}, {nickname}, {giftname}, {coins}, {repeatcount}, {comment}, entre otros.

GET/POSTEjecutar acción por nombre con datos personalizados http://localhost:3199/execute_action?name=ACTION_TEST&username=interactive&nickname=Interactive&giftname=Rose&coins=1&repeatcount=5
GET/POSTEjecutar acción por ID con comentario http://localhost:3199/execute_action?id=1&username=interactive&comment=Hola%20desde%20webhook

Configuración

Conexión RCON al servidor Minecraft. Los mismos datos se usan en la pestaña Minecraft para enviar comandos.

RCON

Asegúrate de habilitar el acceso a RCON en tu servidor, establecer una contraseña y ajustar la configuración correctamente. Cada perfil del panel puede tener su propia configuración guardada al exportar/importar o al usar perfiles guardados.

OBS

Puedes controlar OBS para cambiar escenas y fuentes automáticamente en ciertos eventos. Requiere OBS 28 o posterior. En OBS: Herramientas → Configuración del servidor WebSocket → habilita el servidor e indica el puerto (por defecto 4455) y la contraseña si la activas.

Importante: la conexión WebSocket la abre el servidor Node (donde corre este panel), no tu navegador. 127.0.0.1 solo sirve si OBS y el servidor están en el mismo PC.

STREAMER.BOT

Streamer.bot es una de las herramientas más populares para los streamers. Podrás recibir eventos de Twitch y YouTube, además de ejecutar tus acciones desde Acciones y alertas. En Streamer.bot activa el servidor WebSocket en la pestaña Servers/Clients.

Minecraft ServerTap

Si utilizas el plugin ServerTap (o el mod de TikFinity), ingresa aquí tu nombre de jugador para usar el placeholder de {playername}. Si dejas el campo en blanco, los comandos se ejecutarán para todos los jugadores en el servidor (@p). Elige entre el mod de TikFinity (para un jugador) o el plugin ServerTap (para servidores). ¡No los uses juntos!

Antes de ejecutar el servidor sigue estos pasos:

🧨 Bedrock · Cubo TNT

Minijuego del cubo de TNT con comandos /bedrock.

Versión: 1.21.1
📁 Elegir / cambiar archivo del servidor (.bat)
⚠️
Sigue estos pasos para usar el Cubo TNT:
  1. Primero descarga una versión: Original o Pirata (botones de arriba).
  2. Descomprime la carpeta y pulsa Ejecutar servidor: selecciona el archivo iniciar.bat (solo la primera vez).
  3. Ve a Webhook y Config. y marca la casilla Usar ServerTap. Pon: Nombre del Jugador @p, IP localhost, Puerto 4567, Key tiktok123, y pulsa Probar conexión: debe salir una palomita verde ✅ (eso significa que ya está funcionando).
  4. Entra a tu Minecraft, instala la versión 1.21.1, pulsa Multijugador, escribe localhost y entra al mundo.
  5. Ejecuta el comando para crear el cubo de bedrock (sección Configuraciones, abajo).
  6. ⛔ INDISPENSABLE: NO cierres la ventana negra (la consola del servidor) que aparece al ejecutar: si la cierras, el servidor se apaga y nada funcionará. Si no tienes permisos de administrador (no puedes usar comandos), escribe hasta abajo de la ventana negra: op tu_usuario (pon tu nombre exacto de Minecraft) y pulsa Enter.
  7. Listo: ya puedes personalizar tus alertas en Acciones para que funcionen.

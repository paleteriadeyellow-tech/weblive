⚙️ Configuración

Conexión RCON al servidor Minecraft, OBS, Streamer.bot y ServerTap. Los mismos datos se usan en Acciones y en la pestaña Minecraft.

RCON

Asegúrate de habilitar el acceso a RCON en tu servidor, establecer una contraseña y ajustar la configuración correctamente. RCON, OBS, Streamer.bot y ServerTap son globales: no cambian al cambiar de perfil (igual que Spotify).

Obligatorio para QualityArmory (qa give): el plugin no entiende @p por RCON. Los mobs con execute at @p sí usan tu personaje en el mundo.

OBS

Puedes controlar OBS para cambiar escenas y fuentes automáticamente en ciertos eventos. Requiere OBS 28 o posterior. En OBS: Herramientas → Configuración del servidor WebSocket → habilita el servidor e indica el puerto (por defecto 4455) y la contraseña si la activas.

Importante: la conexión WebSocket la abre el servidor Node (donde corre este panel), no tu navegador. 127.0.0.1 solo sirve si OBS y el servidor están en el mismo PC.

STREAMER.BOT

Streamer.bot es una de las herramientas más populares para los streamers. Podrás recibir eventos de Twitch y YouTube, además de ejecutar tus acciones desde Acciones y alertas. En Streamer.bot activa el servidor WebSocket en la pestaña Servers/Clients.

Minecraft ServerTap

Alternativa a RCON. El nick de Minecraft se configura arriba en la tarjeta RCON (Nombre del jugador).

90%

Cada umbral cubre un rango: desde ese valor hasta el siguiente umbral más alto. Ej.: si pones 100 y luego 200, los regalos de 100 a 199 monedas usan el tamaño del primer umbral; al llegar a 200, ya usa el del siguiente. El umbral más alto cubre todo lo que esté por encima.

🏀 Configurar — Pelotas de fans

🌟 Pelota dorada: cuando alguien se vuelve super fan cae una pelota especial con su foto, más grande y con borde/brillo dorado, por encima de las demás. Se activa sola con el evento de super fan de TikTok (también suma el bono super fan en la pestaña «Usuario y Puntos»).

Tu propia app de Spotify

Recomendado · Development Mode limita a 5 usuarios

Spotify solo deja 5 usuarios por app en modo desarrollo. Para tu live, crea tu propia app y agrégate a ti mismo. Sigue estos pasos exactamente:

  1. 1
    Crear la app
    1. Abre developer.spotify.com/dashboard e inicia sesión con tu cuenta de Spotify (con Premium).
    2. Arriba a la derecha pulsa el botón morado Create app.
    3. En App name escribe un nombre (ej. Livecoins o tu nick).
    4. En App description pon algo como Panel de control para TikTok Live.
    5. En Redirect URI pega exactamente esto y pulsa Add:
    http://127.0.0.1:8888/spotify/callback
    1. Marca la casilla de Developer Terms of Service / términos.
    2. Pulsa Save (o Create) para crear la app.
  2. 2
    Users and Access (quién puede conectar)
    1. En el Dashboard, haz clic en el nombre de tu app para abrirla.
    2. En el menú de la app entra a Users and Access (a veces aparece como User Management).
    3. Pulsa Add user / Add new user.
    4. Escribe el email de la cuenta Spotify con la que harás el live (la misma que usas en la app de Spotify del PC).
    5. Confirma / guarda. Puedes añadir hasta 5 emails (tú + mods de prueba).
  3. 3
    Redirect URI + Client ID en Livecoins
    1. Dentro de tu app pulsa Settings (o Edit settings).
    2. En Redirect URIs debe existir exactamente:
    http://127.0.0.1:8888/spotify/callback
    1. Si no está: pégalo, pulsa Add y luego Save.
    2. Copia el Client ID (Settings → Client ID → Copy).
    3. Pégalo abajo en Client ID de Livecoins (se guarda solo).
    4. Pulsa Iniciar sesión con Spotify y acepta los permisos.

Así cada streamer tiene sus propios 5 cupos y no gastas los de una sola app compartida. Si el login falla con error de redirect, casi siempre falta el URI de arriba o un espacio de más al pegarlo.

🪝 Webhook

Ejecuta tus acciones y videos desde herramientas externas (OBS, Stream Deck, scripts). Funciona solo en la app de escritorio.

⭐
Esta función es Solo Premium
El Webhook y la conexión con OBS / RCON / Streamer.bot están disponibles en el plan Premium. Mejora tu plan para activarlos.
  • Puedes usar esto en OBS Browser Source, Stream Deck (Petición Web), o scripts de Python/NodeJS.
  • Importante: las URLs ya incluyen tu room= (igual que los overlays). Copia y pégalas en Stream Deck.
  • Si tienes el mismo nombre en dos acciones, se ejecutará la primera que encuentre.
  • Si un valor tiene espacios o caracteres especiales, debe ir codificado. Ejemplo: Hola mundo → Hola%20mundo

Tu clave de sala: —

1. Obtener lista de acciones

Devuelve un JSON con el id y nombre de todas las acciones disponibles en el perfil actual.

GETListar Acciones http://localhost:3199/get_actions

2. Ejecutar acción por ID

La forma más segura de ejecutar una acción. El ID no cambia aunque cambies el nombre.

GET/POSTEjemplo ID 1 http://localhost:3199/execute_action?id=1

3. Ejecutar acción por Nombre

Útil si prefieres usar el nombre exacto de la acción. No distingue mayúsculas/minúsculas.

GET/POSTEjemplo por Nombre http://localhost:3199/execute_action?name=ACTION_TEST

4. Obtener lista de videos / batallas

Devuelve un JSON con id, nombre y pantalla de los videos de la pestaña Videos y las animaciones de la pestaña Batallas.

GETListar Videos + Batallas http://localhost:3199/get_videos

5. Ejecutar video / batalla por ID

Reproduce un video o una animación de batalla. El ID no cambia aunque cambies el nombre. Ideal para Stream Deck.

GET/POSTEjemplo por ID http://localhost:3199/execute_video?id=v123

6. Ejecutar video / batalla por Nombre

Misma URL para Videos y Batallas. Usa el nombre exacto. No distingue mayúsculas/minúsculas. Espacios → %20. Opcional: &kind=video o &kind=battle.

GET/POSTEjemplo por Nombre http://localhost:3199/execute_video?name=NOMBRE

Enviar datos personalizados a la acción

Puedes agregar datos extra en la URL para que la acción los use como variables. Estos datos pueden reemplazar valores como {username}, {nickname}, {giftname}, {coins}, {repeatcount}, {comment}, entre otros.

GET/POSTEjecutar acción por nombre con datos personalizados http://localhost:3199/execute_action?name=ACTION_TEST&username=interactive&nickname=Interactive&giftname=Rose&coins=1&repeatcount=5
GET/POSTEjecutar acción por ID con comentario http://localhost:3199/execute_action?id=1&username=interactive&comment=Hola%20desde%20webhook

Advertencia importante sobre TTS

RIESGO DE BANEO

Al activar el TTS, los comentarios de tu chat se leerán en voz alta. Si contienen contenido que incumple las Normas de la Comunidad de TikTok, tu cuenta podría ser sancionada o baneada permanentemente.

Recomendaciones:
  • Usa la lista de palabras prohibidas para filtrar contenido inapropiado
  • Limita el TTS solo a seguidores o suscriptores
  • Monitorea tu chat activamente mientras el TTS esté activo

Livecoins no se hace responsable de sanciones derivadas del uso del TTS. Al activar esta función, aceptas toda la responsabilidad.

Cómo usar tu voz con ElevenLabs

Livecoins no cobra ni paga ElevenLabs: usas tu cuenta y tu API key. El Chat TTS normal (Edge / TikTok / sistema) sigue funcionando si desactivas esta opción.

  1. Crea una cuenta en elevenlabs.io e inicia sesión.
  2. Contrata un plan de pago (mínimo Starter, ~5–6 USD/mes). El plan Free casi no alcanza para un live y el clonado de voz requiere plan de pago. Planes: elevenlabs.io/pricing
  3. Entra a Profile → API Keys (o Ajustes → API Keys) y pulsa Create API Key. Copia la key (empieza por xi- o similar).
  4. En Livecoins → Chat TTS → sección Mi voz · ElevenLabs: pega la API key y pulsa Cargar voces para ver las voces de tu cuenta.
  5. Opción A — Clonar tu voz: pon un nombre, sube un audio limpio de 10–30 segundos (solo tú hablando, sin música) y pulsa Clonar.
    Opción B: elige una voz que ya tengas en ElevenLabs en el desplegable.
  6. Activa «Usar mi voz de ElevenLabs…». Con Chat TTS activado, el chat se leerá con esa voz. Si se te acaban los créditos o la key falla, desactiva el interruptor y volverás a Edge/TikTok/sistema.

Privacidad: la key se guarda en tus ajustes de Livecoins. No compartas la key ni clones voces de otras personas sin permiso.
